**Dip Watch（逢低买入体检）**：基于同样的数据面，评估是否有标的出现**可信的逢低买入机会**（超跌 + 基本面未变坏 + 催化剂可辨识）。

**Reaction Check（消息—股价反应背离体检）**：这是独立于上面两项的**附加**判断点，不替代、不改变上面两项原有的判断标准。对每支标的回溯**最近 1–10 个交易日**内是否出现明确、可检索的重大消息（财报与指引、大额订单/合同、评级与目标价调整、监管与制裁、产品与产能、并购与融资、针对该公司的重大宏观冲击等），先判断该量级消息按常理**应当**引发的方向与幅度，再对比消息公布后至今的**实际**股价走势。判断必须**扣除同期大盘与所属板块的涨跌**，以超额收益而非绝对涨跌为准（美股基准用 SPY/QQQ，半导体用 SOX/SMH，港股与中概用恒生科技指数）：

- **利好不涨（`good_news_weak`）**：出现明确利好，但消息后涨幅显著小于该量级消息应有的反应，甚至横盘或下跌（超额收益 ≤ 0 或远低于预期）→ 说明利好已被提前充分定价、买盘透支、筹码拥挤，后续上行空间有限，**偏向减仓 / 卖出**。
- **利空抗跌（`bad_news_resilient`）**：出现明确利空，但消息后跌幅明显小于该量级消息应有的反应，甚至逆势上涨 → 说明利空已被充分消化、卖压枯竭、估值触底，**偏向逢低买入**。
- 近期无明确重大消息，或股价反应与消息的方向和量级基本相符 → 不填 `reaction` 字段。

**Earnings Watch（财报前瞻）**：检索每支标的的下一次财报发布日期。凡**距今 7 天以内（含当天）**将发布财报的标的，必须给出 `earnings` 字段：财报日期、业绩预测（共识 EPS/营收与关键看点）、上行机会、下行风险。距离财报超过 7 天的标的省略该字段。

## 判定纪律
- 信号必须「可信」：有明确的事件/数据支撑，而非日常波动。宁缺毋滥；绝大多数日子多数标的应为 none 或 watch。
- signal 取值：`none`（无信号）| `watch`（值得关注但不构成操作）| `buy`（逢低买入）| `trim`（减仓）| `sell`（卖出/见顶）。
- signal 非 none 时必须同时给 `signal_brief`：≤12 字的超短原因标签，概括触发信号的核心矛盾（如「财报当日事件风险」「单日涨12%过热」「收购稀释风险」），用于首页一行展示；signal 为 none 时留空字符串。
- 只有 buy / trim / sell 需要写入 alerts 数组（用于提醒）。
- 消息—股价反应背离的纪律：必须同时说清**具体消息与日期**、**观察窗口**（如「财报后 3 个交易日」）、**常理预期反应**、**实际（超额）表现**，四者缺一则不填该字段；只能用大盘普涨普跌解释的走势不算背离；|超额| 小于约 2% 的日常噪音不算背离。该维度是**附加证据**：与见顶 / 逢低体检结论同向时可加强信号（如 watch → trim/sell 或 watch → buy）；若全场只有这一条证据、缺少其他基本面或消息面佐证，signal 最多给 `watch`。
- 全部文字用简体中文；summary ≤ 80 字；signal_brief ≤ 12 字；signal_reason ≤ 120 字；每条 event ≤ 60 字；earnings 的 forecast/opportunities/risks 各 ≤ 80 字；reaction 的 news ≤ 40 字、window ≤ 15 字、expected ≤ 30 字、actual ≤ 50 字、reading ≤ 60 字。
